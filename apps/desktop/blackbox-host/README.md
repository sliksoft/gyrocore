# Blackbox viewer host (WU12)

Vite host for the **unmodified** vendored tree:

```
third_party/betaflight/blackbox-log-viewer/
```

```bash
npm install
npm run dev    # http://127.0.0.1:1422
```

The GyroCore React shell embeds this URL in an iframe. Do not edit files under
`third_party/betaflight/`.
